MOBILE-FIRST, FROM KOTLIN TO SWIFT.

Since September 2022 I've been an Android Mobile Developer at IDEMIA Jakarta, focused on proof-of-concept work for secure element (SIM & NFC) solutions across Android and iOS. These days I'm building a crypto wallet on iOS; before that, my biggest project was integrating CBDC solutions — secure elements plus backend API services — into a mobile app for a client's digital currency initiative. Also, my current project, Crypto Wallet solutions — hardware wallet with security parts - connect with server services, provide new level of Crypto Wallet.

I studied Software Engineering through a Double Degree program at Nanjing Xiaozhuang University and Kalbis Institute, and picked up Android, iOS and cloud fundamentals through Dicoding and Google's Bangkit program.
